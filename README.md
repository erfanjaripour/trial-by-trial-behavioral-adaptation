# Trial-by-Trial Behavioral Adaptation in a Restless Bandit Task

A reproducible analysis of trial-by-trial behavioral adaptation in a four-arm restless bandit task using frequentist mixed-effects modeling.

## Overview

This project examines how participants' behavior changes across repeated trials in a dynamic reward environment and the extent to which individuals differ in their behavioral trajectories.

The analysis focuses on behavioral outcomes rather than estimating latent reinforcement-learning parameters or computational learning mechanisms.

## Research Question

How does behavioral performance evolve across repeated trials, and to what extent do individuals differ in their behavioral trajectories?

## Dataset

The project uses the publicly available **Bahrami2020 Four-Arm Restless Bandit Dataset**.

**Source:** [https://osf.io/f3t2a/overview](https://osf.io/f3t2a/overview)

The dataset contains:

* 975 participants
* 150 trials per participant
* four available options per trial
* trial-specific payoff values for each option
* participant choices
* obtained rewards
* reaction times

The raw dataset is preserved unchanged:

data/raw/DataAllSubjectsRewards.csv

The processed analysis dataset is generated by the preprocessing workflow:

data/processed/processed-data.csv

## Statistical Analysis

The primary analysis uses a logistic mixed-effects model predicting payoff-maximizing choice:

payoff_maximizing_choice ~ (trial_c + trial_c2) * payoff_group +
    (1 + trial_c + trial_c2 | id)

The model estimates **trial-by-trial changes in the probability of selecting an option with the highest trial-specific payoff**, while accounting for individual differences in baseline behavior and behavioral trajectories.

Secondary analyses examine:

* obtained reward,
* log-transformed reaction time,
* choice switching behavior.

Model comparison uses AIC, BIC, and log-likelihood. Likelihood-ratio tests are used only for nested model comparisons. Robustness analyses evaluate alternative random-effects specifications and **linear versus quadratic trial trajectories**.

## Reproducibility

The computational environment is managed using `renv`.

### 1. Clone the repository

git clone <repository-url>

### 2. Restore the R environment

Open R and run:

renv::restore()

### 3. Verify the raw dataset

The SHA-256 checksum of the raw dataset is:

ad5acb1d3206d5302e2233f9d7aa3cb2eb1d7eb59fdc2c9090710944daec1f0d

### 4. Source the preprocessing functions

source("R/preprocessing.R")

Preprocessing is executed through the analysis notebooks.

### 5. Run the analysis notebooks

notebooks/01-data-inspection.qmd
notebooks/02-exploratory-analysis.qmd
notebooks/03-modeling.qmd

Generated figures, tables, and model objects are stored in:

results/

## Reproducibility Principles

* Raw data are preserved unchanged.
* Data processing is scripted and reproducible.
* Exploratory analysis is separated from statistical modeling.
* Analytical decisions and model specifications are documented.
* Figures, tables, and model outputs are generated reproducibly.
* Package versions are recorded in `renv.lock`.

## Data Availability

The dataset is publicly available through the OSF repository. No original data collection was performed for this project.
